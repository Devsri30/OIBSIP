 Voice Assistant using Python

## Overview

A Python-based Voice Assistant that listens to user commands and performs useful tasks such as greeting the user, telling the current date and time, searching the web, and providing voice responses. This project was developed as part of the **Oasis Infobyte Internship Program**.

## Features

* Capture voice input using Speech Recognition
* Respond to greetings with predefined messages
* Tell the current date and time
* Perform web searches on user-specified topics
* Text-to-speech responses using pyttsx3
* Error handling for unrecognized voice commands

## Tech Stack

* Python
* SpeechRecognition
* pyttsx3
* Webbrowser
* Datetime
* SMTPLib (optional)
* NLTK / Transformers (Advanced Features)

## Project Structure

* `main.py` – Main application file
* `requirements.txt` – Required dependencies
* `README.md` – Project documentation

## How to Run

1. Clone the repository.
2. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```
3. Run the project:

   ```bash
   python main.py
   ```

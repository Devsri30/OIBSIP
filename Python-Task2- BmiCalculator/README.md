# BMI Calculator

##  Overview

A Python-based BMI (Body Mass Index) Calculator that helps users determine their BMI using height and weight inputs. The application also classifies the user's health status according to standard BMI categories.

##  Features

* Calculate BMI accurately
* User-friendly input system
* Displays BMI value instantly
* Health category classification (Underweight, Normal, Overweight, Obese)
* Simple and lightweight application

##  Tech Stack

* Python
* Math Module

##  How to Run

1. Clone the repository.
2. Run the Python file:

   ```bash
   python bmi_calculator.py
   ```

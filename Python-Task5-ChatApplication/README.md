#  Chat Application

##  Overview

A Python-based Chat Application that enables real-time communication between users. The project demonstrates networking concepts and message exchange through a simple and interactive interface.

##  Features

* Real-time messaging
* Multiple user communication
* Easy-to-use interface
* Fast message transmission
* Client-server architecture

##  Tech Stack

* Python
* Socket Programming
* Threading

##  How to Run

1. Clone the repository.
2. Start the server:

   ```bash
   python server.py
   ```
3. Start the client:

   ```bash
   python client.py
   ```
